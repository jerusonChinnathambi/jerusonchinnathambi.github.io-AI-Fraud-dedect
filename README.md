# AI Fraud Detection System

## Overview
This project implements an AI-powered fraud detection system using:
- Random Forest
- XGBoost
- LSTM Neural Networks

## Dataset
Financial transaction dataset with fraud labels.

## Features Used
- amount
- oldbalanceOrg
- newbalanceOrig
- oldbalanceDest
- newbalanceDest

## Results
- Random Forest Accuracy: 99.4%
- XGBoost Accuracy: 99.48%
- LSTM Accuracy: 99.32%

## Technologies
- Python
- TensorFlow
- XGBoost
- Scikit-learn
- Streamlit
- Pandas
- Matplotlib

## Run Project
```bash
python3 main.py
streamlit run app.py
```
